# 온라인 섯다 (최대 6인)

가상 칩으로 즐기는 실시간 온라인 섯다 웹 게임입니다. (실제 금전 거래 없음)

## 기술 스택
- 서버: Node.js, TypeScript, Express, Socket.IO, Prisma + SQLite, JWT
- 클라이언트: React, TypeScript, Vite, socket.io-client

## 실행 방법

```bash
npm install
npm run prisma:migrate
npm run dev
```

- 서버: http://localhost:4000
- 클라이언트: http://localhost:5173

`npm run prisma:migrate` 는 최초 1회(또는 스키마 변경 시) 실행하면 됩니다. `server/prisma/dev.db` 파일에 계정/칩 데이터가 저장됩니다.

## 플레이 방법
1. 회원가입 후 로그인 (아이디/비밀번호, 계정별 칩 10,000 지급)
2. 로비에서 "새 방 만들기" 또는 방 코드로 "입장하기"
3. 같은 방에 모인 인원(2~6명)이 모두 "준비 완료"를 누르면 자동으로 한 판이 시작됩니다
4. 카드 1장 배분 → 1라운드 배팅 → 카드 1장 더 배분 → 2라운드 배팅 → 쇼다운 순으로 진행됩니다
5. 삥 / 하프 / 콜 / 다이 / 체크로 베팅하고, 쇼다운 후 팟이 분배됩니다 (나가리 발생 시 재대결)

## 섯다 규칙 요약 (본 구현 기준, 나무위키 표준룰 참고)
- 화투 20장(1~10월, 월별 그림 1장 + 띠 1장) 사용
- 족보(높은 순):
  1. 38광땡(3월광+8월광)
  2. 18광땡 = 13광땡 (동급)
  3. 땡: 장땡(10땡) ~ 1땡
  4. 중간족보: 알리(1+2) > 독사(1+4) > 구삥(1+9) > 장삥(1+10) > 장사(4+10) > 세륙(4+6)
  5. 끗: 갑오(9끗) ~ 망통(0끗)
- 특수 조합(잡이): 암행어사(4월그림+7월그림)는 13/18광땡 보유자가 있을 때만 활성화되어 그 사이 등급으로 승리(타깃 없으면 1끗). 땡잡이(3월광+7월그림)는 1~9땡 보유자가 있을 때만 활성화되어 9땡과 장땡 사이 등급으로 승리(타깃 없으면 망통). 장땡·38광땡은 잡이에 영향받지 않음
- 강제 재대결: 구사(4월+9월)를 든 사람이 있는데 최고패가 알리 이하면 폴드 안 한 전원이 재대결. 멍텅구리구사(4월그림+9월그림)는 최고패가 9땡 이하일 때 전원 재대결(광땡·장땡 제외)
- 동점(같은 등급)이면 나가리 — 동점자끼리만 카드를 새로 받아 재대결(안테 재징수 없음, 카드 2장 바로 배분 후 베팅 1회)
- 안테(게임 시작 시 기본 판돈) 1,000칩. 삥은 이전 배팅금액+1,000칩(배팅 시작 후엔 사용 불가), 하프는 배팅 전이면 1,000칩·있으면 이전 배팅금액+2,000칩 (server/src/config.ts에서 조정 가능)
- 땡값(추가 배당), 광박/멍박/흔들기 등은 아직 구현하지 않음
- 올인 시 사이드팟은 지원하지 않고 단순화되어 있음 (친목/캐주얼 플레이 기준)
